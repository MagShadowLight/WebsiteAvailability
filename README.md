# Website Availability V0.1

This repository contains scripts and tools for monitoring the availability of websites. It provides a way to check whether websites are up and running, and can be used for various purposes such as website monitoring, uptime tracking, and alerting.

## Problem:
If my personal website experiences downtime or slow performance due to server issues, network connectivity problems, power outages, or other technical difficulties, it can negatively affect my job opportunities and user experience. 

These issues could result in lost website traffic and visitors encountering errors when trying to access my website. Therefore, it is important to maintain the website's availability and ensure that it remains accessible to users.

I also want to ensure that my other websites, whether they are currently under development or have already been built and deployed, remain available and accessible to users. This is crucial for maintaining a positive user experience and avoiding any potential negative impact on my job opportunities.

## Solution:
The solution involves developing a website availability monitoring system using Python that regularly checks the status of my personal website and other websites I manage.

The system will provide real-time notifications when issues are detected, allowing me to take immediate action to investigate and resolve problems. Additionally, the monitoring system will help me identify potential issues before they negatively impact website availability and user experience.

The notification channels will include email, desktop, and website notifications. The system will also maintain logs containing additional information about detected issues, such as when a website becomes unavailable and potential reasons for the failure.

The system will monitor HTTP status codes, HTTPS connectivity, response times, SSL certificate validity and expiration dates, as well as other relevant metrics to ensure the overall health and performance of the websites.

To avoid unnecessary notifications caused by temporary network issues or intermittent failures, the system will perform multiple consecutive checks before sending an alert. Once the failure threshold is reached, it will immediately send a notification so I can investigate the issue and resolve it as soon as I am available.   

Furthermore, this project will provide me with an opportunity to learn Python and gain practical experience while building upon my existing C# programming skills and knowledge.
